# Registration Form

This project contains a basic HTML registration form created for a DevOps lab experiment.

## Features
- Simple student registration form
- Fields for personal details and contact information
- Course selection dropdown
- Gender selection
- Email and password fields
- GitHub repository setup for version control and publishing

## File
- `registration-form.html`

## Purpose
This form was created to practice frontend form design and GitHub-based project publishing in a DevOps environment.
